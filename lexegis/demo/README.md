# Static bench

`index.html` is a self-contained demonstration of the deterministic core — injection triage, the
cross-document discrepancy sweep, and the e-graph congruence decision — reimplemented in JavaScript
so it runs with no server. Open the file directly, or serve the directory.

It is a demo, not the engine: forensics, semantic markup, the verification tiers and the provenance
ledger live in `../backend` and need a running service.
